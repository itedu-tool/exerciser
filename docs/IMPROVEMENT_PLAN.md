- [ ] Удалить поле `Score` из `Exerciser.WebApi/DTOs/FinishAttemptRequest.cs`
- [ ] Удалить поле `Score` из `AnswerSubmissionDto`
- [ ] Удалить клиентский расчёт баллов в `Exerciser.FrontEnd/Student/src/views/AttemptView.vue`
