## [1.0.0] - 2026-06-10

### 🚀 Добавлено

#### Backend (.NET 10 / ASP.NET Core)

- **Минимальное API** для управления экзаменами (CRUD).
- **Модели данных:** `Exam` и `Question` с поддержкой UUID v7 в качестве первичного ключа в MongoDB.
- **DTO для импорта и ответов API:** `ImportExamDto`, `ExamDetailsDto`, `ExamSummaryDto`, `HealthCheckResponseDto`.
- **MongoDB репозиторий (`ExamRepository`)** с методами `CreateAsync`, `GetAllAsync`, `GetByIdAsync`, `DeleteAsync` и `UpdateAsync`.
- **Валидатор импорта (`ExamImportValidator`)** со следующими правилами:
  - Название экзамена обязательно, макс. 500 символов.
  - Описание макс. 2000 символов.
  - Экзамен должен содержать хотя бы один вопрос.
  - Для каждого вопроса проверяется текст, тип, варианты ответов и правильные ответы (включая уникальность вариантов, для `SingleChoice` — ровно один правильный ответ).
- **Сервис миграций MongoDB (`MongoDbMigrationService`)** для автоматического создания индексов:
  - Текстовый индекс на поле `Title`.
  - Обычный индекс на поле `CreatedAt` (по убыванию).
- **Кеширование:** интерфейс `ICacheService` с реализацией `DistributedCacheService` на основе `IDistributedCache` (поддерживает Redis и MemoryCache).
- **Rate Limiting:**
  - `fixed`: 100 запросов/минуту (очередь 10) — для большинства эндпоинтов.
  - `import-sliding`: 10 запросов/час (очередь 5) — для эндпоинта импорта.
- **Логирование:** Настроен NLog с выводом в консоль и файлы (JSON, текст, отдельный файл для ошибок), ротация файлов раз в день, хранение до 30 архивов.
- **CORS:** Настраивается через переменную `CORS_ALLOWED_ORIGINS` (разрешённые источники).
- **Health Check:** Эндпоинты `/health` и `/api/v1/health` возвращают статус сервиса, временную метку и временную зону.
- **OpenAPI:** Автоматическая генерация спецификации (`/openapi/v1.json`) и интерактивная документация Scalar UI (`/scalar/v1`).

#### Frontend (Admin Panel)

- **Административная панель** на Pug + Bootstrap 5 (Bootswatch).
- **Управление экзаменами:**
  - Импорт экзамена из JSON-файла (форма с выбором файла).
  - Список экзаменов с кнопками просмотра и удаления.
  - Модальное окно для просмотра деталей экзамена (вопросы, варианты, правильные ответы).
  - **Редактирование экзамена:** отдельная страница `edit.html` с возможностью изменять название, описание, вопросы, варианты и правильные ответы (добавление/удаление вопросов и вариантов).
- **Страница диагностики API:** проверка доступности различных эндпоинтов (`/health`, `/`, `/scalar/v1`, `/api/v1/health`, OpenAPI спецификации).
- **Динамическая смена тем:** поддержка 13 цветовых схем Bootswatch с сохранением выбора в `localStorage`.
- **Общий модуль `utils.js`:** содержит функции `showMessage`, `apiRequest`, `escapeHtml` и другие, используемые на всех страницах.

#### DevOps & Инфраструктура

- **Docker Compose:** Описаны сервисы `mongodb`, `redis` и `webapi` с healthcheck'ами и зависимостями.
- **Dockerfile:** Multi-stage сборка на основе Alpine Linux, non-root пользователь (UID 1001).
- **GitHub Actions:** Автоматическая сборка и публикация образа `exerciser-webapi:latest` на Docker Hub при пуше в ветку `master` (и по требованию).
- **Postman коллекция:** Полный набор запросов для тестирования API (Health, Exams, API Information) с переменными окружения и встроенными тестами.
- **Документация:**
  - Подробный `README.md` с описанием установки, API, архитектуры, конфигурации и устранения неполадок.
  - `API_EXAMPLES.md` с примерами запросов и ответов.
  - `POSTMAN_SETUP.md` с руководством по импорту и использованию Postman.

### 🛠 Изменено

- **Обновление README:** добавлены разделы об архитектуре, безопасности, rate limiting, кешировании, валидации и Docker.
- **Рефакторинг фронтенда:**
  - Выделение общих функций в `utils.js` (устранение дублирования).
  - Перемещение всех скриптов в папку `scripts/` для улучшения структуры.
  - Настройка ESLint для корректной работы с глобальными переменными.

### 🐛 Исправлено

- **Обработка ошибок в API:** Добавлена базовая обработка исключений для возврата осмысленных сообщений об ошибках.
- **Валидация импорта:** Исправлены несколько багов, связанных с проверкой правильных ответов для `SingleChoice` и `MultipleChoice`.
- **Фронтенд:** Устранены проблемы с отображением ошибок при импорте и загрузке списка экзаменов.

### 🚧 Устарело

- **Legacy health-check эндпоинт (`/health`)** помечен как устаревший. Рекомендуется использовать версионированный эндпоинт `/api/v1/health`.

### 🔒 Безопасность

- **Non-root пользователь** в контейнере (UID 1001).
- **Alpine Linux** в качестве базового образа для минимизации поверхности атак.
- **Rate Limiting** для защиты от DDoS и брутфорса.
- **Валидация размера файла** при импорте (максимум 10 MB).

### 📦 Зависимости

Обновлены следующие пакеты до актуальных версий:
- MongoDB.Driver → 3.9.0
- NLog → 5.2.8
- NLog.Web.AspNetCore → 5.3.2
- Scalar.AspNetCore → 1.2.5
- Microsoft.Extensions.Caching.StackExchangeRedis → 10.0.0

### 📌 Известные проблемы

- **Redis кеширование:** Реализован интерфейс `ICacheService`, но активно используется только MemoryCache (задел на будущее).
- **Аутентификация MongoDB:** В `docker-compose.yml` отключена (для простоты разработки). Для production рекомендуется включить и задать пароль через переменные окружения.
- **HTTPS:** Не настроен (требуется настройка сертификатов или использование обратного прокси).
