# 📚 Exerciser – Система тестирования студентов

**Exerciser** – веб-приложение для проведения тестирования студентов. Преподаватели загружают вопросы в формате JSON, управляют экзаменами (редактирование, настройка количества вопросов каждого типа), а студенты проходят тесты через удобный интерфейс на Vue 3.

**Версия:** 1.2.0  
**Дата:** 2026-06-15

---

## 🚀 Быстрый старт (разработка)

### Требования

- [Docker](https://docs.docker.com/get-docker/) и [Docker Compose](https://docs.docker.com/compose/install/) (для инфраструктуры)
- [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0)
- [Node.js](https://nodejs.org/) (v20+)

### Запуск инфраструктуры (MongoDB, Redis)

```bash
git clone https://github.com/itedu-tool/exerciser.git
cd exerciser
docker compose up -d
```

### Запуск бэкенда (API)

```bash
cd Exerciser.WebApi
dotnet run
```

API будет доступен: `http://localhost:8080`  
Документация Scalar UI: `http://localhost:8080/scalar/v1`

### Запуск фронтендов (для разработки)

#### Административная панель (Pug + Bootstrap)

```bash
cd Exerciser.FrontEnd/Admin
npm install
npm start   # http://localhost:3000
```

#### Студенческий клиент (Vue 3)

```bash
cd Exerciser.FrontEnd/Student
npm install
npm run dev # http://localhost:3001
```

> **Примечание:** На данном этапе статические файлы не копируются в `wwwroot` бэкенда, фронтенды запускаются независимо. Для продакшена потребуется отдельная настройка раздачи статики (планируется в следующих релизах).

## 📋 API Endpoints (v1)

Базовый URL: `http://localhost:8080/api/v1`

| Метод | Эндпоинт | Описание |
|-------|----------|-----------|
| `GET` | `/health` | Проверка здоровья (legacy) |
| `GET` | `/api/v1/health` | Проверка здоровья (v1) |
| `POST` | `/api/v1/exams/import` | Импорт экзамена из JSON |
| `GET` | `/api/v1/exams` | Список экзаменов (метаданные) |
| `GET` | `/api/v1/exams/{id}` | Полный экзамен (вопросы, ответы) |
| `PUT` | `/api/v1/exams/{id}` | Обновление экзамена |
| `DELETE` | `/api/v1/exams/{id}` | Удаление экзамена |
| `POST` | `/api/v1/sessions/start` | Создание сессии (логин студента) |
| `POST` | `/api/v1/attempts/start` | Начать попытку |
| `POST` | `/api/v1/attempts/{id}/finish` | Завершить попытку |
| `GET` | `/api/v1/attempts/{id}/result` | Результат попытки |
| `GET` | `/api/v1/groups` | Список групп со студентами |
| `POST` | `/api/v1/groups` | Создать группу |
| `POST` | `/api/v1/groups/import` | Импорт группы из JSON |
| `POST` | `/api/v1/groups/{id}/students` | Добавить студента |
| `GET` | `/api/v1/analytics/attempts/last` | Последние завершённые попытки по студентам и экзаменам |

### Пример импорта экзамена

**Файл `exam.json`:**

```json
{
  "title": "Основы C#",
  "description": "Проверка знаний по основам C#",
  "questions": [
    {
      "text": "Что такое CLR?",
      "type": "TextInput",
      "correctAnswers": ["Common Language Runtime"]
    },
    {
      "text": "Какой модификатор доступа является самым закрытым?",
      "type": "SingleChoice",
      "options": ["public", "private", "protected", "internal"],
      "correctAnswers": ["private"]
    }
  ]
}
```

**Запрос:**

```bash
curl -X POST http://localhost:8080/api/v1/exams/import -F "file=@exam.json"
```

**Ответ (201 Created):**

```json
{
  "id": "507f1f77bcf86cd799439011",
  "title": "Основы C#",
  "questionsCount": 3
}
```

### Получить список экзаменов

```bash
curl http://localhost:8080/api/v1/exams | jq
```

Пример ответа:

```json
[
  {
    "id": "507f1f77bcf86cd799439011",
    "title": "Основы C#",
    "description": "Проверка знаний по основам языка C#",
    "questionsCount": 3,
    "singleChoiceCount": 1,
    "multipleChoiceCount": 1,
    "textInputCount": 1,
    "singleChoiceToShow": 0,
    "multipleChoiceToShow": 0,
    "textInputToShow": 0,
    "createdAt": "2026-06-10T10:30:00Z"
  }
]
```

## 🎨 Административная панель

**Возможности:**
- Импорт экзаменов из JSON
- Редактирование экзамена:
    - Изменение названия, описания
    - Добавление/удаление/копирование вопросов
    - Выбор типа вопроса (один вариант / несколько вариантов / ввод текста)
    - Редактирование вариантов ответов и отметка правильных
    - **Указание количества вопросов каждого типа для показа студенту** (0 = все)
- Просмотр деталей экзамена (модальное окно)
- Удаление экзаменов
- Управление группами и студентами
- - **Аналитика:** таблица с последними попытками студентов, фильтрация по группам и экзаменам, сортировка по любым столбцам, цветовая индикация прогресса.
- Диагностика API

**Запуск в режиме разработки:**
```bash
cd Exerciser.FrontEnd/Admin
npm start
```

## 👨‍🎓 Студенческий клиент (Vue 3)

**Возможности:**
- Вход по группе и студенту
- Список доступных экзаменов с отображением:
    - Общего количества вопросов и разбивки по типам
    - Количества вопросов, которое будет показано (по каждому типу)
- Прохождение теста с:
    - Таймером (1 час, автоматическая отправка при истечении)
    - Прогресс-баром отвеченных вопросов
    - Навигационной панелью с номерами вопросов (цветовая индикация: отвечен/не отвечен/текущий)
    - Автоматическим сохранением ответов в `sessionStorage` (восстановление при перезагрузке)
    - Плавной прокруткой к вопросу и временной подсветкой
- Страница результатов с детализацией по каждому вопросу (ответы, баллы, правильные ответы)

**Запуск в режиме разработки:**
```bash
cd Exerciser.FrontEnd/Student
npm run dev
```

## 🔒 Безопасность и конфигурация

### Переменные окружения (файл `.env`)

```ini
MONGO_ROOT_USERNAME=admin
MONGO_ROOT_PASSWORD=changeme
MONGO_DATABASE=exerciser_db

REDIS_PASSWORD=

ASPNETCORE_ENVIRONMENT=Production
CORS_ALLOWED_ORIGINS=http://localhost:3000,http://localhost:5000,http://localhost:3001
LOG_LEVEL=Info
```

### CORS

Настраивается через `CORS_ALLOWED_ORIGINS`. В продакшене укажите домены фронтендов.

### Rate Limiting

- `fixed` – 100 запросов/мин (общие эндпоинты)
- `import-sliding` – 10 запросов/час (импорт экзамена)

### Логирование (NLog)

- Консоль с цветовой дифференциацией
- Файлы JSON и текст в папке `logs/` (ротация каждый день, хранение 30 дней)
- Отдельный файл для ошибок
